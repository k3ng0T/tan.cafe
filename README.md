# ТАҢ — онлайн-меню

Статический сайт без сервера и оплаты. Гость выбирает блюда, открывает корзину и показывает экран заказа официанту. Корзина хранится в браузере посетителя.

## GitHub Pages

Загрузите **содержимое** папки `dist` в корень репозитория GitHub. В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/ (root)`. Все пути относительные, поэтому сайт работает и по адресу вида `https://имя.github.io/репозиторий/`.

## Изменение меню и фотографий

Названия, цены и категории находятся в `dist/menu.js`. У каждой позиции есть ID: например, `breakfast-1` — первая позиция раздела «Завтраки». Порядок позиций определяет ID, поэтому при изменении порядка проверьте привязку фотографий и сохранённые корзины.

Положите фотографии, например, в `dist/assets/dishes/` и добавьте пути в объект `dishPhotos` в конце `menu.js`:

```js
export const dishPhotos = {
  'breakfast-1': 'assets/dishes/ovsyanaya-kasha.jpg',
};
```

Пока фотография не добавлена или файл недоступен, показывается заглушка. Большое изображение в шапке — иллюстрация сервировки, а не фотография блюда кафе.

Локальный просмотр: `py -m http.server 8000 --directory dist`, затем откройте `http://localhost:8000`.
