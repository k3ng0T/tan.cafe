# ТАҢ — онлайн-меню

Статический сайт без сервера и оплаты. Гость выбирает блюда, открывает корзину и показывает экран заказа официанту. Корзина хранится в браузере посетителя.

## GitHub Pages

Загрузите файлы этой папки, включая `index.html`, `app.js`, `menu.js`, `styles.css` и папку `assets`, в корень репозитория GitHub. В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/ (root)`. Все пути относительные, поэтому сайт работает и по адресу вида `https://имя.github.io/репозиторий/`.

## Изменение меню и фотографий

Названия, цены и категории находятся в `menu.js`. У каждой позиции есть ID: например, `breakfast-1` — первая позиция раздела «Завтраки». Порядок позиций определяет ID, поэтому при изменении порядка проверьте привязку фотографий и сохранённые корзины.

Иллюстрации сгенерированы по названиям блюд и находятся в `assets/dishes/`. Одинаковые напитки разных объёмов и порции крылышек используют общие изображения. Подсказки для генерации перечислены в `assets/dishes/PROMPTS.md`.

Чтобы заменить иллюстрацию фотографией кафе, положите файл, например, в `assets/dishes/` и добавьте путь в объект `customDishPhotos` в конце `menu.js`:

```js
export const customDishPhotos = {
  'breakfast-1': 'assets/dishes/ovsyanaya-kasha.jpg',
};
```

Если файл недоступен, показывается заглушка. Большое изображение в шапке — иллюстрация сервировки, а не фотография блюда кафе.

Локальный просмотр: `py -m http.server 8000`, затем откройте `http://localhost:8000`.
